Decisiones arquitectónicas (ADRs implícitos)

Providers aislados + modelos Pydantic

Principio II: cada fuente es un boundary. arcgis_utils.CapaConfig centraliza params/consulta; errores nunca se silencian (Fail Loud).

Caché solo éxitos · TTL inyectable

CHIP→lote+geometría cacheado; errores y “no encontrado” nunca. LRU128 + reloj inyectable para tests contractuales.

Degradación por bloque, no fatal

UPL null + warning; RAG vacío + causa; 5xx → BLOQUE_DEGRADADO. El informe siempre retorna 23 bloques aunque fallen 5 fuentes.
